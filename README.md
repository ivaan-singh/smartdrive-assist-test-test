SmartDrive Assist is a modern accessibility-focused mobility assistance project designed to improve independence, control, and user experience for wheelchair users through smart technology integration.

## Overview

This project explores how intelligent systems, sensors, and responsive controls can enhance wheelchair mobility and everyday accessibility.

The goal is to create a clean, efficient, and user-friendly mobility solution that combines:

- Smart sensor systems
- Remote or assisted control
- Safety-focused functionality
- Modern UI/UX concepts
- Accessibility-first design

## Installation

Clone the repository:

```bash

```

Open the project:

```bash
cd smartdrive-assist-test
```

Then launch `index.html` in your browser.
